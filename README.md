# AI-Assisted Digital Commerce Management System

## 📌 Project Overview

The **AI-Assisted Digital Commerce Management System** is a web-based application developed using Python and Flask to manage basic digital commerce activities.

The system helps users manage products, customer orders, stock levels, and sales reports. It also includes an AI-assisted feature for generating product descriptions.

## 🚀 Features

* 📦 Product Management

  * Add products
  * View products
  * Edit products
  * Delete products

* 🛒 Order Management

  * Add customer orders
  * View orders
  * Edit orders
  * Delete orders
  * Automatically reduce product stock when an order is placed

* 🤖 AI Product Description Assistant

  * Enter product name, category, and features
  * Generate a ready-to-use product description

* 📊 Reports

  * Total products
  * Total orders
  * Available stock
  * Total sales

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/antonicaevelyn-glitch/Digital-Commerce-Management-System.git
```

### 2. Open the project folder

```bash
cd Digital-Commerce-Management-System
```

### 3. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 4. Install Flask

```bash
pip install flask
```

### 5. Run the application

```bash
python app.py
```

### 6. Open in the browser

```text
http://127.0.0.1:5000
```

## 🤖 AI-Assisted Feature

The project includes an AI-assisted product description feature that generates a product description from the product name, category, and key features entered by the user.

## 🎯 Project Objective

The objective of this project is to develop a simple digital commerce management system that demonstrates product management, order processing, inventory tracking, reporting, and AI-assisted content generation.
